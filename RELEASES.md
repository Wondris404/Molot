# MOLOT releases

MOLOT releases are published separately and use semantic version tags.

## 3.5.0 — AI Improvement Version

The repository history starts with the sanitized 3.5.0 source snapshot. Its Windows
installer is published separately from source code and contains no development database,
uploads, logs, backups, downloaded AI model, or personal school data.

## 0.3.0 — preserved stable installer

The original 0.3.0 Windows installer and checksum are preserved as a separate release.
Its exact source snapshot was not retained before development continued, so this repository
does not pretend that the newer 3.5.0 source is the source tree for 0.3.0.
